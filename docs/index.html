為什麼要做這個

跟一般注音輸入法的差別

寫 Markdown、commit message、Slack 技術討論時，最常卡住的是 ` 跳出符號表、標點變全形、英文被當成注音。碼注音把這幾件事改成工程師習慣的樣子。

情境一般注音輸入法碼注音
`打開符號表直接輸出 `，``` 區塊也一樣
' [ ] ? ! :變成全形 、「」？！：預設半形原樣（想要全形可在偏好設定打開）
`foo`、user_id標點被吞掉，或 foo 被當成注音打到一半的鍵當英文送出，再接標點
中英切換要按 Caps Lock 或 Shift自動判斷；Shift 單擊仍可手動切
網址、路徑得切英文才打得出 google.com英文後面打 . / - 會接續英文

中英混打

  • 不用切換輸入法直接打 docker、kubectl，英文詞典加上技術用詞會自動認出來；按空白候選窗同時列出 google／Google／GOOGLE 和中文。
  • 短英文也認得db、js、ip 這種兩個字母的英文會被認出來。像注音的（ui、ai、go）會跳英文提示，按 Tab 或 ↓ 選英文，空白照常出中文。後面直接接注音也會拆對：ui跟、ai的。
  • 網址、路徑、底線英文後面打 . / - 會接著打英文（google.com、src/app、foo-bar），打回注音就自動回中文。
  • 數字直出組不出注音的數字（123456、2026）直接顯示數字，Enter 就送出。組得出字的（283＝打）仍是中文，要數字就按 Tab。

標點與程式碼

  • 反引號直出` 永遠是 `，行內程式碼、``` 區塊都不用切換。
  • 半形標點_ ( ) [ ] { } < > = ' " ! ? : 照英文鍵盤輸出，不轉全形。
  • Tab 送原始鍵組字中按 Tab，打到一半的鍵照鍵盤原樣送出。要打分號就 ; Tab。

選字與學習

  • 按鍵還原英文被轉成中文時，按 ↓ 打開候選，最後一項就是當初按的鍵，選它換回原樣。
  • 越用越準選過的字、改過的詞、詞語接續習慣都會記住。同一串注音連續兩次改字後上屏，就自動學成新詞。
  • 情境詞庫一個領域一組專有名詞，打開的情境詞會優先出現。可以手動加詞，或把提示詞給 ChatGPT、Claude 等外部 AI，把它回的 JSON 貼回來逐項確認後匯入。
  • 本機 AI（選用）開啟智慧輸入後，停手時會用本機的 Breeze 模型補句、修同音錯字，不連網，約佔 4 GB 記憶體。

介面

  • 按鍵顯示＋注音標籤組字區顯示你按的鍵，下方藍色小標籤是注音。不習慣可在「選字窗」頁關掉，改回顯示注音。
  • 外觀主題淺色、深色、跟隨系統；主色有靛藍、竹綠、琥珀、玫瑰、石墨。
  • 簡體輸出偏好設定或選單列打開「輸出簡體中文」，照打注音，送出簡體字。

其他

  • 貓貓模式預設開啟。貓踩鍵盤、小孩亂按時自動鎖住輸入，游標旁顯示 🐱。Esc 連按兩下或停手 5 秒解鎖。開關在「中英混打」頁。
  • 一鍵更新偏好設定的「更新」頁會顯示新版內容，可以直接下載安裝，完成後自動重啟。
安裝

安裝步驟

需要 macOS 14 以上。碼注音沒有付費的 Apple 開發者憑證，所以要先手動解除 macOS 的下載隔離。

  1. 下載 zip 並解壓縮

    到 GitHub Releases 的 latest-main 下載 CodeZhuyin-0.1.xx.zip，解壓後會得到「碼注音 CodeZhuyin 0.1.xx」資料夾，裡面有 CodeZhuyin.app、安裝碼注音.command 和說明檔。

  2. 解除隔離並執行安裝程式

    打開「終端機」，輸入 cd （後面留一個空格），把解壓出來的資料夾拖進終端機視窗後按 Enter，再執行：

    $ xattr -dr com.apple.quarantine . && ./安裝碼注音.command

    安裝程式會把輸入法複製到 ~/Library/Input Methods 並向系統註冊；有舊版會先關掉再換掉。

    為什麼不能直接雙擊？新版 macOS 已經不能用「右鍵 › 打開」略過 Gatekeeper。另一個方法是雙擊被擋之後，到「系統設定 › 隱私權與安全性」按「仍要打開」。

  3. 登出再登入

    macOS 的限制：新輸入法要重新登入才會出現在清單裡。只有第一次安裝需要。

  4. 加入輸入來源

    系統設定 › 鍵盤 › 輸入來源 › 編輯 › ＋ › 繁體中文 › 選「碼注音」加入。之後從選單列切到碼注音就能開始打字。

  5. 看一下操作說明

    點選單列的「碼」圖示 › 操作說明…，裡面有所有快捷鍵。偏好設定也從這個選單打開。

維護

更新與疑難排解

怎麼更新

打開偏好設定的「更新」頁，有新版就按下載安裝，完成後會自動重啟。也可以照上面的安裝步驟重跑一次新的 zip，不用再登出。

更新後還是舊版行為

很舊的版本（0.1.0 附近）更新完不會自己重啟。在終端機執行下面這行，切回碼注音時就會載入新版：

$ pkill -x CodeZhuyin

選單列圖示還是舊的「融」

這是 macOS 的圖示快取，安裝包裡已經是「碼」。登出再登入，或在輸入來源裡把碼注音移除後重新加入。

英文被轉成中文了

按 ↓，候選窗最後一項就是你按的原始鍵，選它換回來。學壞的詞可以從選單列的「學習資料…」逐筆刪掉。

突然打不出字

可能是貓貓模式誤判，游標旁會有 🐱。Esc 連按兩下或停手 5 秒就會解鎖；常誤判可以到「中英混打」頁關掉。

移除

把 ~/Library/Input Methods/CodeZhuyin.app 丟到垃圾桶，再到輸入來源移除「碼注音」。學習資料在 ~/Library/Application Support/CodeZhuyin/，要清乾淨就一起刪。
